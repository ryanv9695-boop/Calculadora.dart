# 🧮 Projeto Calculadora em Flutter

Boas-vindas ao meu projeto! 👋 

Este é um aplicativo de **Calculadora** desenvolvido utilizando [Flutter](https://flutter.dev/). Criei este projeto com o objetivo de colocar a mão na massa, praticar a criação de interfaces e entender melhor como o Flutter funciona na prática.

## 🚀 O que foi construído aqui?

Para fazer essa calculadora ganhar vida, desenvolvi os seguintes pontos:

*   **Operações Matemáticas:** O app é capaz de realizar as quatro operações básicas de forma precisa (Soma, Subtração, Multiplicação e Divisão).
